Have you ever heard of I2P? It's awesome!


Hey there! Just wanted to inform you that this is my first post!

Have you ever heard of I2P?

Chances are, you have not.

But let me in-TOR-duce you to it!

I2P is like TOR ... but also not ... TOR.

The main point of TOR is that your traffic towards
websites hops through three community runned nodes (often called relays or onions) that are encrypted.

But the thing that makes it secure, and anonymizing, is that each node can only see a certain part about the traffic.

For example: the guard relay can only see **YOUR** IP address (guard relay is reffering to the relay that your computer talks to FIRST, in the TOR network.), but the exit
node can only see the exit data, but not YOUR IP address (It can only see the middle relay's IP address).

TOR also has something called onion services which are basically websites, that also go behind the TOR network

These, however, are an after-thought

However, for I2P, this is the main point (But just with an .I2P address; not an onion one. )

I2P (instead of using onion routing), uses something called garlic routing.

But that's not the main point.

The main point is about the .I2P addresses, and the entire ecosystem that goes along with it.

So which one is better? I2P or TOR?

Well that's up to YOU to find out!
